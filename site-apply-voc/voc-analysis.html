케어브릿지 예약 페이지 유입 분석

웹 애널리틱스(세션 리플레이 툴) 무료 플랜 데이터를 사용한 21일간 전수 분석. 24,180 세션이 어떤 경로로 예약 페이지에 도달하는지, 어디서 이탈하는지, 그리고 이를 바탕으로 프로덕트팀이 주도할 개선 우선순위를 정리합니다.

⚠️ 포트폴리오 데모 · 가상 브랜드 「케어브릿지」 · 목업 데이터 — 실제 서비스·수치와 무관한 기획 프로토타입입니다.
분석 방법 · 종합 판단

고객 행동은 하나의 지표로 단정하지 않고, 정량 데이터와 정성 데이터를 교차해 종합적으로 판단합니다. 서로 다른 소스가 같은 방향을 가리킬 때만 개선 가설로 채택합니다.

  • Amplitude — 이벤트·퍼널·리텐션으로 무엇이 일어났는지 정량 측정
  • 히트맵 · 세션 리플레이 — 스크롤·클릭·이탈 지점을 관찰해 왜 그랬는지 정성 진단
  • VOC(고객 문의·리뷰) — 사용자의 실제 언어로 불편의 맥락과 우선순위 신호 확보
  • 전환·이탈·검색 로그 — 퍼널 단계별 병목을 뒷받침하는 근거 데이터

→ 정량(무엇이)과 정성(왜)을 결합한 교차 검증으로 원인을 좁히고, 그 근거 위에서 개선 우선순위를 정합니다. 이 리포트도 유입 로그·퍼널·정성 관찰을 함께 놓고 판단한 결과입니다.

한 줄 요약
예약 페이지에 도달한 사용자의 80%가 정확히 같은 3단계 경로(메인 → 검색 → 예약)를 거쳤고, 그중 검색 페이지에서 가장 큰 이탈이 발생합니다. 검색 페이지 UX 개선이 예약 전환율을 올릴 가장 큰 지렛대입니다.

해석

메인 페이지는 누구나 통과하는 통로 역할이지만 자체적으로 예약을 유도하는 힘은 없습니다. 반면 검색·쿠폰·이벤트·혜택 페이지는 예약 유도 효율이 메인의 2~3배입니다. 특히 검색은 예약 도달자의 80% 이상이 거친 페이지이면서 예약 유도 효율도 메인의 2.4배라서, 사이트에서 실질적인 예약 엔진 역할을 하고 있습니다.

FINDING 02

진짜 병목은 검색 페이지

3.4×
메인 → 검색 도달률과 검색 → 예약 도달률을 각각 1%p 개선했을 때, 검색 → 예약 개선이 3.4배 더 많은 예약을 만듭니다. 검색 페이지 UX가 이 사이트의 가장 큰 지렛대입니다.

메인 → 검색 → 예약 페이지의 3단계 흐름을 세션 단위로 정확히 추적했습니다. 아래 다이어그램은 각 단계에서 몇 명이 다음 단계로 넘어가고 몇 명이 이탈했는지 보여줍니다.

메인 → 검색 이탈은 절대 규모가 가장 큽니다. 메인에 온 사람 중 3분의 2 이상이 검색조차 시도하지 않고 나갑니다. 반면 검색 → 예약 이탈은 이탈률 91%로 훨씬 심각합니다. 검색까지 한 사람 중 92%가 예약 없이 나갑니다.

어느 지점의 개선이 더 효과적인가

각 단계의 도달률을 1%p 개선했을 때 예상되는 예약 증가는 다음과 같습니다.

개선 대상 1%p 개선 시 예약 증가
메인 → 검색 도달률 약 +20 예약
검색 → 예약 도달률 약 +69 예약 (3.4배)

검색 페이지 개선의 임팩트가 훨씬 크지만 디자인·개발 리소스가 더 많이 필요합니다. 마케팅·콘텐츠 리소스만 있다면 메인 페이지에서 검색으로 유도하는 CTA(검색바 강화, 인기 검색어 노출 등)를 개선하는 게 상대적으로 쉬운 개선책입니다.

해석

쿠폰을 세션 중에 발견한 사용자는 사이트 평균의 3.7배 전환합니다. 반면 광고나 딥링크로 쿠폰 페이지에 바로 떨어진 사용자는 예약 없이 전원 이탈했습니다. 차이의 원인은 후자에게 사이트 컨텍스트가 없기 때문입니다. 쿠폰만 봐서는 쿠폰의 의미와 예약 필요성을 이해할 시간이 없어요.

시사점

쿠폰 페이지를 광고 랜딩페이지로 사용하는 캠페인이 있다면 재검토가 필요합니다. 대신 사이트 내부(메인, 검색 결과 페이지, 예약 페이지 진입 직전 등)에서 쿠폰 노출을 강화하는 게 훨씬 효과적입니다.

참고: 직접 유입 그룹의 53 세션은 통계적으로는 얇은 표본입니다. "정확히 0%"라기보다 "사이트 평균 3.16%에 못 미치는 확연히 낮은 수준"으로 이해하시고, 53 세션이 어떤 광고·캠페인에서 왔는지 트래픽 소스 감사를 먼저 하시는 게 좋습니다.

복지몰 UI/UX 개선 우선순위

프로덕트팀이 오너십을 갖고 디자인·개발·마케팅·CX와 협업해서 진행할 개선 항목입니다. 임팩트 예측과 근거 데이터를 함께 정리했습니다.

01

검색 페이지 이탈률 67.3% 개선

검색 결과 페이지 UX 리디자인, 결과 없음 케이스 대응, 필터·정렬 개선. 예약 경로의 80%가 이 페이지를 통과하며, 개선 효율이 다른 지점의 3.4배.

데이터 신뢰도와 한계

신뢰할 수 있는 부분

모든 세션 수·전환율·이탈률·평균 시간 등 수치는 웹 애널리틱스 툴이 전수 캡처한 원본 데이터입니다. 웹 대시보드에서 동일 조건으로 조회하면 같은 값이 나옵니다. 무료 플랜의 월 20만 세션 한도 대비 이 사이트는 월 약 3만 5천 세션이므로, 샘플링 없이 전체 세션이 캡처된 상태입니다.

방법론 관련 한계

무료 플랜에서는 세션 리플레이 툴의 정식 "이동 경로 분석(Journey Analysis)" 기능이 API로 열리지 않아, 단계별 유입 흐름 분석(Funnel)을 여러 번 조회해서 유입 경로를 재조합했습니다. 이 방식은 "어떤 페이지를 거쳤는가"를 측정하는데, "예약 페이지 바로 직전에 어떤 페이지를 봤는가"를 정확히 특정하지는 못합니다. 마우스 클릭 마찰 지표(Rage Click), 급회전 이탈(U-Turn), JavaScript 오류 분석도 유료 애드온이라 이번 분석에서는 다루지 못했습니다.

추가 확인이 필요한 지점

검색 페이지 이탈률 67%의 실제 이유(검색 결과 페이지 히트맵·리플레이 정성 분석 필요), 데스크톱 예약 흐름의 마찰점(데스크톱 세션 리플레이 정성 분석), 직접 유입 쿠폰 세션 53건의 트래픽 소스(광고 캠페인 감사)를 우선 확인 대상으로 권장합니다.
