CARE BRIDGE 복지몰 메인 개선 데모

Amplitude 활동 데이터 · 2026-07-06 우선순위 회의를 반영한 예약 전환 중심 재편안

개선 메인 + 추천 병원 빠른 시술 비교표

맞춤 추천 아래에 추천 병원 빠른 시술 비교표를 신설한 개선안입니다. 같은 시술(스마일라식)을 여러 추천 병원끼리 우대가·전용 혜택·후기로 한 줄 비교해, 검색·상세 진입 없이 첫 화면에서 바로 병원을 고를 수 있게 합니다.

1
빠른 시술 비교표 신설 추가

추천 병원을 병원 · 프로그램명 · CARE BRIDGE 우대가 · 전용 혜택 · 후기 5개 열로 한 줄 비교합니다. 행을 누르면 해당 시술 상세로 이동합니다.

2
전용 혜택 색상 태그

당일수술 -20만원(그린) · 쿠폰 할인 가능(블루) · 자가혈청 무료(퍼플)를 색상 칩으로 구분해 병원별 혜택 차이를 즉시 인지합니다.

3
우대가·후기 동시 비교

CARE BRIDGE 우대가와 후기 별점을 나란히 노출해 가격만이 아닌 후기 기준 선택을 돕습니다.

·
‘더 보기’ → 관심 시술 비교 페이지 신규 페이지

메인의 비교표는 대표 관심 시술 1개만 보여줍니다. 더 보기를 누르면 관심 등록한 시술(스마일라식·보톡스·임플란트 등) 전부를 시술별 비교표로 모아 보는 새 페이지로 이동합니다.

기준: 개선 메인(TO-BE) + 추천 병원 비교표 · 프로토타입

시술 리스트 — 실제(AS-IS) 대비 변경점
01
최저가 보장제 배너 → AD 영역으로 변경 변경

AS-IS의 ‘같은 병원, 다른 가격? 가격 조율 +5,000P 보상’ 최저가 보장제 배너 자리를 AD(스폰서) 인벤토리로 교체했습니다. 활용도가 낮던 배너를 광고·특가 매출 영역으로 전환.

02
지역 선택 개선

기존 지역 칩을 지역 선택 버튼으로 개선 — 누르면 온보딩식 지역 선택 화면에서 관심 지역을 선택·변경하고 재조회합니다. 관심 지역은 온보딩·메인과 공유됩니다.

03
진료과 선택 추가 추가

진료과 선택 기능을 신설했습니다 — 진료과 버튼(바텀시트)에서 진료과를 고르면 해당 진료과 시술로 필터됩니다. (선택한 진료과는 온보딩 관심정보에 반영)

04
필터 · 정렬 아이콘 영역 분리 변경

AS-IS는 정렬(인기순)·지역·진료과·필터 칩이 한 줄에 섞여 가로 스크롤됐습니다. TO-BE는 [지역·진료과·정렬] 셀렉트 영역과 [쿠폰 추가할인·당일할인·특가전·오늘 예약가능] 필터 칩 영역을 별도로 분리했습니다.

관심 지역 선택 화면 지역 버튼 → 진입
1
관심 지역 복수 선택 (최대 3곳) 멀티선택

한 번에 최대 3곳까지 관심 지역을 선택할 수 있습니다. 선택한 지역은 온보딩·메인과 공유되어 리스트에 함께 반영됩니다.

2
지역별 시술·병원 수 표시 추가

인기 상권을 병원 밀집순으로 정렬하고, 각 지역 카드에 해당 지역에 존재하는 시술·병원 수(예: 시술 10 · 병원 6)를 함께 노출해 어디에 매물이 많은지 한눈에 보여줍니다.

3
현재 위치로 설정

현재 위치 기반으로 내 주변 병원을 먼저 볼 수 있습니다. (위치 권한 기반 자동 매칭)

4
지역·지하철역 직접 검색

목록에 없는 지역은 지역·지하철역 검색으로 직접 찾아 추가할 수 있습니다.

▶ 직접 해보기
  1. 최저가 보장제 자리의 AD 배너 확인 — 광고·특가 인벤토리로 전환
  2. 지역 버튼 → 지역 선택·변경 후 재조회 / 진료과 버튼 → 바텀시트에서 진료과 선택
  3. 정렬(인기순)과 필터 칩이 별도 영역으로 분리된 레이아웃 확인

예약 플로우 개선 — 선(先)신청 · 후(後)상세입력
01
예약 신청 마찰 최소화

기존 예약 화면에서 진료 대상 · 병원 전달사항 · 추가 상담 희망 시술을 제거하고, 내원 희망 일시 + 약관 동의만으로 ‘예약 신청하기’ 즉시 신청되도록 간소화했습니다.

02
팝업 → 접수 페이지 전환

신청 후 완료 팝업 대신 새 페이지가 열립니다. 상단에 ‘예약 신청이 접수되었어요’ 안내(기존 팝업 내용)를 노출합니다.

03
상세정보 후속 수집 → DB 업데이트

접수 페이지 하단에서 병원 전달사항 · 추가 상담 희망 시술을 추가로 입력받아 예약 건에 이어붙여 DB 업데이트합니다. 진료 대상은 예약 신청 단계에서 선택합니다. ‘나중에 입력’도 가능.

04
기대 효과

예약 신청 단계의 입력 부담을 낮춰 신청 전환율 ↑, 필수 상세는 접수 직후 자연스럽게 수집해 완결성도 유지합니다.

▶ 직접 해보기
  1. 날짜(예: 16일) · 시간(오후 05:00) 선택 → 약관 동의 → ‘예약 신청하기’
  2. 접수 페이지 상단 접수 안내 확인
  3. 하단에서 전달사항 · 추가 상담 입력 → ‘입력 완료·저장하기’ (DB 업데이트)

기준: welfaremall.stage.carebridge.kr/reservation · 프로토타입

예약 수정 — 취소만 → 변경 + 취소
01
AS-IS = 예약 취소만

현행 마이 › 예약 내역에서는 예약 취소하기만 제공됩니다. 일정이 바뀌면 취소 후 재예약해야 해 이탈이 발생합니다.

02
TO-BE = 예약 변경하기 신설

기존 취소 기능은 그대로 두고, ‘예약 변경하기’를 추가해 일시(날짜·시간)·진료 대상·병원 전달사항·추가 상담 희망 시술·쿠폰을 취소 없이 한 화면에서 수정합니다. 단, 예약대기 상태만 변경 가능 — 예약확정·예약완료는 변경 불가.

03
변경은 병원 승인 후 확정 승인 플로우

‘변경 신청하기’를 누르면 즉시 확정이 아니라 병원 관리자에 변경 요청 상태값으로 전달됩니다. 예약은 ‘병원 확인 중’으로 표시되고, 병원에서 확인·승인하면 그때 예약이 변경됩니다.

·
취소 사유 = 일정 변경 대응 취소 플로우

취소 사유 대다수가 일정 변경인 점을 반영 — 취소 플로우(‘예약 취소하기’ 진입) 안에서 ‘변경으로 처리’를 제안해 불필요한 취소·재예약을 막습니다. 화면 위 별도 마커는 없습니다(취소 시트 내부 동작).

·
기대 효과 효과

일정 변경 이탈을 예약 유지로 전환 — 예약 취소율↓, 실내원 전환율↑. (측정 지표 · 화면 마커 없음)

▶ 직접 해보기
  1. TO-BE ‘예약 변경하기’ → 새 날짜·시간 선택 → 변경 신청하기 → ‘병원 확인 중’ 표시(병원 확인 후 일시 반영)
  2. AS-IS ‘예약 취소하기’ → 취소 사유(일정 변경)뿐 — 취소만 가능
  3. TO-BE ‘예약 취소하기’ → ‘예약 변경으로 처리’ 제안 확인

기준: welfaremall.stage.carebridge.kr/profile/reservation · 취소사유 분석 · 프로토타입

스샷2 좌측 사이드바 영역 → 개인화 광고·특가 인벤토리

데스크톱 웹 좌측 사이드바 영역(스샷2)이 현재 CARE BRIDGE 꿀팁·공지사항·QR 등 저활동 콘텐츠로 비어 있습니다. 여신티켓이 같은 자리를 ‘실시간 인기 시술 + 특가전’ 인벤토리로 쓰는 것처럼, 이 사이드바를 개인화 광고·특가 인벤토리로 전환합니다.

01
실시간 인기 시술 랭킹

검색·예약 로그 기반 실시간 Top 10(순위 추이·BEST/NEW)으로 트렌드 탐색을 촉진합니다.

02
개인화 + 스폰서(광고비 지불) 노출

고객의 관심 진료과·지역에 매칭되는 병원/시술 중 광고비를 지불한 제휴 병원을 AD로 상단 우선 노출합니다. 개인화 매칭이므로 광고여도 관련성이 높습니다.

03
어드민 배너 설정 = 영업의 무기

이 AD 영역은 어드민에서 노출 병원·시술·지역/진료과·순서·기간을 직접 설정할 수 있습니다. 영업팀이 제휴 협상 중인 병원을 원하는 지역·진료과 자리에 배너로 노출해, 광고 인벤토리를 영업의 무기로 활용합니다. (제휴 유치·업셀 협상 카드)

·
기대 효과 효과

미활용 영역을 광고 매출 인벤토리로 전환하는 동시에, 개인화 매칭으로 예약 전환도 함께 끌어올립니다. (측정 지표 · 화면 마커 없음)
